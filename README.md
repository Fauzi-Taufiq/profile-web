# Portfolio — Muhammad Taufiq Al Fauzi

Portfolio personal statis yang dibuat dengan HTML, CSS, dan JavaScript tanpa proses build atau dependensi tambahan.

## Menjalankan secara lokal

Cara paling sederhana adalah membuka `index.html` di browser.

Atau jalankan server statis dari folder proyek:

```bash
python -m http.server 8000
```

Kemudian buka <http://localhost:8000>.

## Isi website

- Profil dan ringkasan minat.
- Keahlian berdasarkan area pengembangan.
- Proyek pengembangan web, skripsi machine learning, dan desain UI/UX.
- Pengalaman profesional dan sertifikasi.
- Tautan repository untuk proyek yang memiliki repository publik.
- Riwayat pendidikan.
- Tautan kontak GitHub.

Navigasi mobile, tahun copyright, dan indikator menu aktif ditangani oleh `script.js`. Gaya responsif, fokus keyboard, dan preferensi reduced motion diatur dalam `style.css`.
